
# OpenClaw AI Operating Manual

## Mental Model
OpenClaw is an orchestration framework.

## When Adding a Tool
1. Define schema
2. Register tool
3. Test invocation

## When Adding a Skill
1. Create instructions
2. Register skill
3. Validate context injection

## When Adding a Provider
1. Configure auth
2. Register provider
3. Validate model access

## Troubleshooting Workflow
1. Verify gateway
2. Verify provider
3. Verify tool execution
4. Verify session state
